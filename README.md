# Deskripsi Aplikasi

Cars Rent adalah aplikasi web penyewaan mobil berbasis Laravel yang memungkinkan user menyewa mobil secara online dan admin mengelola data serta persetujuan booking.

__Alur User:__
* User: daftar/login → pilih mobil → tentukan tanggal → booking → tunggu approval → lanjut pembayaran via WhatsApp
* Admin: kelola mobil & booking → approve/reject → kirim notifikasi email

__Fitur utama:__
Katalog & filter mobil
Sistem booking dengan perhitungan harga otomatis
Riwayat booking
Dashboard admin + statistik
Notifikasi email otomatis (pending)

__Teknologi:__
Laravel, MySQL, Blade + Tailwind, Javascript, Vite, Laravel Breeze

__Kesimpulan:__
Project ini adalah sistem rental mobil lengkap dengan alur booking, manajemen admin, dan notifikasi otomatis.
